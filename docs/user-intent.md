# User intent (Part 1)

Read against the master prompt only. There is no earlier chat in this session.

- Decision psychology. The user is locking a fantasy lineup and a pre-game read. Every number needs a grade, a range, and a "what changes if" line. Point estimates alone fail the request.
- Cognitive load. Density is wanted in layers: one-line verdict, scannable panel, tap for the deep dive. The same card order on every game.
- Trust. Previous failure mode was an app that died outside Claude. Show data age and source. Trends carry a "why it may be noise" note. A model-versus-market gap is not an edge. The engine has not been backtested; the status line must say so.
- Novelty. Night, month, rest, travel, refs, altitude, schedule density, and a "new this refresh" feed, all gated. With no historical backfill yet, cards stay below the Validated tier.
- Autonomy. Runtime must not call Grok, Claude, xAI, or a connector.
- Loss aversion. Alerts for late tags, line moves, and lock inside 60 minutes, plus a changes diff.
